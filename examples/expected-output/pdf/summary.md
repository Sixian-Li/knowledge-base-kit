# Measurements and review workflow — Reading guide

## Overview

A two-page, self-authored fixture pairs a table and formula with a branching
workflow. All measurements are fictional.

## Prerequisites

No domain background is needed. Preserve numerical precision and arrow direction.

## Key Steps

1. Read Alpha = 1.25 L and Beta = 0.75 L; their total is 2.00 L.
2. Preserve the control sample 0.00 L as a value.
3. Follow Intake → Validate. Pass leads to Publish; fail leads to Revise.
4. Request a fresh check after revision; the source does not show automatic approval.

## Configuration Reference

Green denotes Publish and orange denotes Revise. The PDF has two pages.

## Common Pitfalls

Do not remove zero values, reverse arrows or invent a return arrow from Revise.
The fixture is not a real laboratory protocol.
