# A tiny knowledge library — Reading guide

## Overview

Keep source-backed full documents and short reading guides in a local Markdown
library. Read catalog → summary → full text to control how much material you open.

## Prerequisites

A source document, a local workspace and a way to compare the result to the source.

## Key Steps

1. Put the source in the inbox.
2. Extract and review it in a draft directory.
3. Check structure, links, math and source coverage.
4. File the reviewed document in an appropriate category.

## Configuration Reference

The demonstration has Alpha = 1.25 L, Beta = 0.75 L and Total = 2.00 L.
The control value 0.00 is a value, not missing data.

## Common Pitfalls

The measurements are invented. A structural validator cannot prove factual
accuracy; compare the generated document with its source.
