# Contributing

Explain the concrete problem and include a small self-authored reproducer.
Never attach private documents, credentials, account logs or extracted personal
content to issues or pull requests. See [maintenance](docs/maintaining.md) for tests.

Keep changes focused. Add regression tests for extraction, validation, installation
or worker protocol behavior. Tests must be offline and cannot invoke authenticated
model CLIs. Preserve original-source bytes and explicitly document format limits.

Contributions are provided under the repository's AGPL-3.0-only license. Third-party
code needs compatible licensing, source attribution and complete required notices.
No contributor license agreement is required for this release.
