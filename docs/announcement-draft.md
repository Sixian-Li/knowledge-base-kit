# Announcement draft

I turned my local document-to-knowledge workflow into Knowledge Base Kit: a small
open-source toolkit for Claude Code and Codex that keeps original sources,
detailed Markdown, short reading guides and a navigable catalog together.

It includes PDF/DOCX/HTML/notebook extraction, one-image worker sessions and checks
for links, structure and formulas. It is an agent-assisted workflow: generated
content still needs source review. There is an offline demo and English/Chinese
onboarding so you can inspect the result before using a model account.

Add the actual public repository URL here when publishing. Do not announce a
star target, universal lossless extraction or unsupported platforms as guarantees.
