# Knowledge Base Kit 0.1.0

Initial standalone release for building source-backed Markdown knowledge bases
with Claude Code or Codex. Documents keep their original attachment, full text,
summary, category and useful related links.

Included: portable workspace initialization; shared project-local skills; static
PDF/DOCX/HTML/notebook extraction; one-image workers with bounded retries;
structure/link/archive/TeX checks; bilingual onboarding and self-authored examples.

The main agent still generates and reviews documents. Complex layouts and model
outputs need source comparison. Local smoke tests exercised both CLI backends on
the included two-page PDF; consult the compatibility record for exact versions
and the repository's Actions page for hosted CI results.

Original code/documentation: AGPL-3.0-only. Bundled/dependent components retain
licenses recorded in THIRD_PARTY_NOTICES.md. Private documents and accounts are
not included. Start with the offline demo before processing your own material.
